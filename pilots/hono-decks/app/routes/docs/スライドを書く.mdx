# Author an MDX deck

<span data-doc-sentinel="DOCS_BODY_AUTHORING_EN" hidden />

## Deck and slide structure

The opening frontmatter block contains deck metadata. Later separators start new slides, so a bare separator cannot be used as a thematic break inside a slide.

## Notes and generated modules

Notes and MDX comments become presenter notes. Edit MDX sources rather than generated modules.
