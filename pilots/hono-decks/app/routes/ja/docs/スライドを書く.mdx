# MDXでスライドを書く

<span data-doc-sentinel="DOCS_BODY_AUTHORING_JA" hidden />

## デッキとスライド

ファイル先頭のフロントマターはデッキ情報、その後の区切り線は新しいスライドの開始を表します。単独の区切り線をスライド内の水平線としては使えません。

## ノートと生成モジュール

notesとMDXコメントは発表者ノートとして扱われます。生成先を直接編集せず、MDXソースを更新します。
