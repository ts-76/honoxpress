# はじめに

MDXで書き、必要な場所にIslandを添える。読みやすく、軽やかで、自分で育てられるドキュメントを作ります。

<span data-doc-sentinel="DOCS_BODY_JA_8e42" hidden />

[Read in English](/docs/getting-started) · [ホーム](/)

## ローカルで起動

開発サーバーを起動して、最初のページを開きましょう。ルートも部品もスタイルも、プロジェクト側で編集できます。

## 操作できるカウンター

静的なページに、小さなIslandで状態を持たせます。別のページから戻ると、カウンターは最初から始まります。
