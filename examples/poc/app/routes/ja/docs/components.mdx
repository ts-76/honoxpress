## Tabs

<Tabs labels={["pnpm", "npm"]} ariaLabel="Package manager">
  <TabPanel index={0}>pnpm add honoxpress</TabPanel>
  <TabPanel index={1}>npm install honoxpress</TabPanel>
</Tabs>

<Tabs labels={["Preview", "Source"]} ariaLabel="Example view" selectedIndex={1}>
  <TabPanel index={0}>Preview content</TabPanel>
  <TabPanel index={1}>Source content</TabPanel>
</Tabs>

Props: `labels` is a non-empty array, `ariaLabel` names the tab list, `selectedIndex` defaults to `0`. Each `TabPanel.index` matches its label. Arrow keys, Home, and End select tabs.

```mdx
<Tabs labels={["First", "Second"]} ariaLabel="Example">
  <TabPanel index={0}>First content</TabPanel>
  <TabPanel index={1}>Second content</TabPanel>
</Tabs>
```

## Your components

<ProjectNote>A custom component is registered once and used here without an import.</ProjectNote>

Add an import and an entry to the registry. `useMDXComponents(overrides)` merges per-render overrides after the defaults. Unknown or incorrectly cased component names fail during MDX compilation when `remarkDocsComponents` is configured.
